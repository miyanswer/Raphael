# ARCH_TITLE: visual_racing_error_calc_fix

## 1. システム概要と決定された採用技術

### システム概要
本設計書は、ビジュアルレーシングAIノード（`course_lap_node.py`）において継続している「常に左旋回を続けてしまい、芝生に突っ込んで緊急停止（EMERGENCY）する」不具合を最終的に解消するための修正設計である。
実行ログの解析結果より、過去の設計（`visual_racing_center_x_fix`）で指示した「画面中心の動的計算（`center_x = image_width / 2.0`）」が正しく反映されておらず、コード内に未だ固定値 `400` を用いた誤差計算（`error = 400 - target_x`）が残存していることが判明した。
本改修では、制御ロジックから固定値 `400` のハードコードを完全に根絶し、シミュレータ画像（幅640px等）の動的な中心座標（320.0）を基準とした誤差（Error）計算ロジックを100%確実に適用する。

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` (AI制御ノード)
画像処理コールバック内のPID制御用の誤差計算、およびデバッグログ出力に渡す値の計算ロジックにおいて、以下の改修を徹底する。

*   **【★修正】誤差(Error)計算における固定値ハードコードの完全排除**
    *   コード内を `400` または `error = 400 - target_x` で検索し、ハードコードされている箇所をすべて特定・削除する。
    *   代わりに、OpenCV画像（`cv_image`）の形状から動的に幅を取得し、中心を求めるロジックを**誤差計算の直前**に必ず実行するよう記述する。
    *   **必須実装ロジック:**
        ```python
        # 1. 画像幅の動的取得 (例: 640)
        image_width = cv_image.shape[1]
        
        # 2. 画面中心X座標の算出 (例: 640 / 2.0 = 320.0)
        center_x = image_width / 2.0
        
        # 3. 正しい基準を用いた誤差(Error)の計算
        # ※ ここで絶対に 400 などの固定値を使わないこと
        error = center_x - target_x
        ```
    *   **期待される結果:**
        *   例として `TargetX` が `350` （アウト寄り）の場合、修正前は `400 - 350 = +50`（左旋回）となっていたが、修正後は `320.0 - 350 = -30.0` となり、正しく右旋回（アウト側へのステアリング）の制御値が出力されるようになる。
        *   この修正により、不要な左旋回が消滅し、直進時の安定と正しいアウト・イン・アウトの軌道制御が実現する。

## 4. データ・制御の処理フロー

改修適用後の、1フレームあたりの正しいデータ処理と制御フローは以下の通りとなる。

```text
【毎フレームのビジュアルレーシング制御フロー】

1. [Image Callback] 画像の取得
   └─ /camera/image_raw を受信し、cv_imageに変換 (例: 幅640px)

2. [Image Processing] 特徴抽出とステート決定
   ├─ マスク処理による黒色路面・芝生の抽出
   ├─ 安全判定（芝生超過で EMERGENCY なら緊急停止・return）
   └─ ステート判定（STRAIGHT, PRE_CURVE, TURNING等）と重心(Cx)の算出

3. [Dynamic Error Calculation] 動的中心座標と誤差の計算（★本改修の最重要ポイント）
   ├─ target_x = Cx + offset      (ステートに応じた目標座標の決定)
   ├─ image_width = cv_image.shape[1]  (★常に画像オブジェクトから幅を取得)
   ├─ center_x = image_width / 2.0     (★動的中心座標、例:320.0)
   └─ error = center_x - target_x      (★固定値400を排除した正しい誤差計算)

4. [PID Control] 制御値(v, w)の算出
   └─ 正しい error 値（+/-）を用いて、ステアリング角速度(w)をPID演算

5. [Debug Logging] 状況出力
   └─ 計算結果（State, Cx, TargetX, 正しいError, v, w）を info ログで出力

6. [Motor Output] コマンド送信
   └─ 算出された Twist を /cmd_vel へ Publish
```
