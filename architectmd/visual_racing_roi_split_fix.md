# ARCH_TITLE: visual_racing_roi_split_fix

## 1. システム概要と決定された採用技術

### システム概要
本設計は、ビジュアルレーシングAIにおいて「開始直後（直線上）にもかかわらず、遠くに見えるカーブ（C1）の黒色領域に重心が引っ張られ、左旋回してしまう」という不具合を解消するための設計書である。
画像処理において、画面全体から単一の重心を計算する既存ロジックを廃止し、**「関心領域（ROI）の上下分割」**を導入する。画面上部（遠景）はカーブの先読みと速度制御（ステート切り替え）のみに使用し、画面下部（足元）の重心情報のみを用いてステアリング制御の目標座標（`TargetX`）を決定することで、ラインに沿った安定した直進と確実な旋回を実現する。

### 決定された採用技術（既存維持）
| 項目 | 採用技術 |
|------|---------|
| 言語 | Python 3.10+ |
| 3Dシミュレータ | Panda3D (既存シミュレータ維持) |

| ROS 2通信・画像処理 | `rclpy`, `geometry_msgs/Twist`, `sensor_msgs/Image`, `cv_bridge`, `OpenCV` (`cv2`) |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` (AI制御側)
ビジュアルサーボのための画像処理部分において、「画像の上下分割」と「独立した役割定義」を実装する。

*   **【★修正1】画像の上下分割（ROI設定）**
    *   受信した画像をHSV変換し、黒路面マスク（`black_mask`）や白線マスクなどを生成した後、マスク画像を上下にスライスする。
    *   画像高さ（`h`）の半分など、任意のY座標（例：`split_y = int(h / 2)` または `int(h * 0.6)`）を境界とする。
    *   実装イメージ:
        ```python
        h, w = mask.shape[:2]
        split_y = int(h / 2)  # 例: 画面中央で分割
        
        # 画面上部（遠景: カーブ先読み用）
        upper_mask = mask[0:split_y, :]
        # 画面下部（足元: ステアリング用）
        lower_mask = mask[split_y:h, :]
        ```

*   **【★修正2】画面上部を用いたステート検知（カーブ先読み）**
    *   `upper_mask` のモーメント（重心）や黒領域の面積・偏りを用いて、「前方にカーブがあるか」を判定する。
    *   重心が大きく左に偏っている場合、ステートを `PRE_CURVE` や `TURNING` に遷移させ、速度を `SPEED_SLOW` に設定する。
    *   **仕様の意図:** 遠くのカーブ情報をステアリング計算から排除し、速度調整のためだけに使う。

*   **【★修正3】画面下部を用いたステアリング目標（TargetX）の算出**
    *   ステアリングのための黒色重心（`Cx`）は、**`lower_mask`（画面下部）のみ**から `cv2.moments(lower_mask)` を用いて計算する。
    *   X座標は画面全体の幅（0〜`w`）と一致するためそのまま使用できる。
    *   算出された下部重心 `Cx` に対して、直進時（`STRAIGHT`）はアウト寄りオフセット、旋回時（`TURNING`）はイン寄りオフセットを足し合わせ、最終的な `TargetX` を決定する。
    *   前回の修正（極性の適正化）で実装した `error = (w / 2.0) - TargetX` の制御式にこの値を流し込む。
    *   **仕様の意図:** 遠くのカーブが見えていても、足元のラインが真っ直ぐであれば重心は中央付近になり、車体は直進を維持する。

## 4. データ・制御の処理フロー

本改修によって画像情報の入力と制御値の出力フローが以下のように最適化される。

```text
【毎フレームのビジュアルレーシング・サイクル】

1. [Image Callback] 画像の取得とHSVマスク化
   └─ OpenCVで黒色路面、芝生(緊急停止用)のマスクを生成する。

2. [ROI Split] 画像の上下分割
   ├─ upper_mask (Y: 0 ～ split_y) ──► 遠景エリア
   └─ lower_mask (Y: split_y ～ h) ──► 足元エリア

3. [State Decision] カーブ先読みと速度設定
   ├─ upper_mask の黒面積や重心Xを分析。
   ├─ 左に大きく偏っていれば「PRE_CURVE」等へ状態遷移。
   └─ 現在のステートに応じて cmd_vel.linear.x (直進/減速) を決定。

4. [Steering Control] 目標値（TargetX）の計算
   ├─ lower_mask のみの重心(Cx)を算出（※遠くのカーブに影響されない）。
   ├─ ステートに応じたオフセット(OFFSET_OUT/IN)をCxに加算し、TargetXを決定。
   └─ error = (画像幅/2) - TargetX を算出。

5. [Motor Output] コマンド送信
   ├─ PID制御により error から cmd_vel.angular.z を計算。
   └─ 機体に対して Publish (直線では直進、足元がカーブなら旋回)。
```
