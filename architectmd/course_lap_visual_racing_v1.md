## 1. システム概要と決定された採用技術

### システム概要
社長およびCTOとの合意に基づき、外周周回ノード（`course_lap_node.py`）を抜本的に改修する。
オドメトリによる絶対的な区間管理（L1, C1など）を一旦完全に廃止し（後日別手法で実装予定）、**カメラ画像情報をフル活用したビジュアルサーボ制御**に移行する。
「黒い路面」の重心をベースにセンタリングしつつ、「白いライン」からカーブを先読みして動的オフセットをかけ、**アウト・イン・アウトおよびスローイン・ファストアウト**のレーシング軌道を実現する。また「緑の芝生」を危険領域として検知し緊急ブレーキをかける安全機構を備える。

| 合意項目 | 決定内容 |
|---------|---------|
| 走行制御のベース | オドメトリ依存を廃止。黒色路面の重心を用いたセンタリングPID制御をベースとする |
| カーブ先読み（白線検知） | 画像上部の白線エッジの傾き/消失からカーブを検知し、ステートを切り替える |
| アウト・イン・アウト | 直線状態では目標重心をアウト側にオフセット。カーブ検知時は目標をイン側にオフセットする |
| スローイン・ファストアウト | 直線時に加速し、カーブ検知（PRE_CURVE）で即座に減速指定を行う |
| 安全装置（芝生検知） | 画像下部に「緑色（芝生）」が一定割合以上検出された場合、緊急停止する |
| 区間管理（現在地把握） | **今回は実装しない。** 後日、オドメトリ以外の確実な手法で実装する（社長指示事項） |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` ― 画像ベースのレーシングノード

画像処理のみで自律的にコースの形状を読み取り、最速ラインを攻めるロジックを実装する。

#### (1) パラメータの再定義
不要になったオドメトリ関連や緑レーン追従パラメータを削除し、新たな画像処理・制御パラメータを定義する。

```python
# ─────────────────────────────────────────
#  レーシング制御パラメータ
# ─────────────────────────────────────────
SPEED_FAST          = 0.6      # 直線走行速度（ファストアウト）
SPEED_SLOW          = 0.25     # カーブ旋回速度（スローイン）
STEER_KP            = 0.005    # ステアリング 比例ゲイン
STEER_KD            = 0.001    # ステアリング 微分ゲイン

# 動的オフセット（画像幅=640pxを想定。正が右、負が左への目標ズレ）
OFFSET_OUT          = -50      # 直線時のアウト寄り（左回りコースなら右へ寄る場合は+、左へは-）※コース向きに応じて調整
OFFSET_IN           = 80       # カーブ時のイン寄り（左回りなら左へ寄る）

# 画像処理 HSV閾値（シミュレータ環境に合わせる）
BLACK_V_MAX         = 50       # 路面（黒）検出用 Value上限
WHITE_V_MIN         = 200      # 白線（白）検出用 Value下限
GREEN_H_RANGE       = (35, 85) # 芝生（緑）検出用 Hue範囲

# 安全装置閾値
EMERGENCY_GREEN_RATIO = 0.15   # 画面下部ROIで緑が15%を超えたら緊急停止
```

#### (2) ステートマシンの定義
オドメトリに基づく区間管理（L1, C1...）を廃止し、相対的な視覚ステートに置き換える。

```python
class State:
    INIT           = "INIT"
    STRAIGHT       = "STRAIGHT"       # 直線（アウト寄り・高速）
    PRE_CURVE      = "PRE_CURVE"      # カーブ進入前検知（イン寄りへ目標移動・スローイン開始）
    TURNING        = "TURNING"        # カーブ旋回中
    EMERGENCY      = "EMERGENCY"      # コースアウト危機（芝生検知による停止）
```

#### (3) 画像処理ロジック（`image_callback` 内での実装要件）
毎フレームのカメラ画像に対し、以下の3つの解析を行う。

1. **緑色（芝生）の検知 [安全装置]**
   - 画面の下部30%（Y=450〜640）をROIとする。
   - HSVで緑色ピクセルをカウントし、割合が `EMERGENCY_GREEN_RATIO` を超えたら `State.EMERGENCY` に強制遷移し、速度・角速度を `0.0` にして停止する。

2. **白色（白線）の検知 [カーブ予測]**
   - 画面の上部〜中間部（例: Y=200〜400）をROIとする。
   - 左右の白線の傾き、あるいは片側の白線の消失を検知する。
   - 「白線が急激に曲がっている」または「奥の黒色領域の幅が極端に狭まる/偏る」状態を検知したら `State.PRE_CURVE` に遷移。
   - カーブを抜け、再び奥まで直線が続く状態を検知したら `State.STRAIGHT` に戻る。

3. **黒色（路面）の重心算出とステアリング制御 [メイン制御]**
   - 画面全体または中間部以下の黒色領域の重心 (Cx, Cy) を算出する。
   - **目標X座標（TargetX）の決定:**
     - `State.STRAIGHT` 時: 画面中央X(320) + `OFFSET_OUT`
     - `State.PRE_CURVE` および `State.TURNING` 時: 画面中央X(320) + `OFFSET_IN`
   - **PID制御:** `error = TargetX - Cx` を入力として角速度（Angular Z）を計算する。

## 4. データ・制御の処理フロー

今回の改修によるノード内部の処理ループ（毎フレーム）は以下の通り。

```text
[image_callback] (毎フレーム実行)
  │
  ├─► 1. カメラ画像をHSV変換
  │
  ├─► 2. 安全確認 (緑マスク)
  │      └─ 下部に緑が多いか？ ─(YES)─► 【EMERGENCY】 Twist(0,0)発行して終了
  │
  ├─► 3. 前方形状解析 (白マスク/黒マスク上部)
  │      ├─ カーブが迫っている？ ─► State = PRE_CURVE
  │      ├─ 旋回中？            ─► State = TURNING
  │      └─ 直線が開けている？    ─► State = STRAIGHT
  │
  ├─► 4. 動的目標設定 (レーシングライン)
  │      ├─ STRAIGHT時 : TargetX = 画面中央 + OFFSET_OUT, Speed = SPEED_FAST
  │      └─ CURVE時    : TargetX = 画面中央 + OFFSET_IN,  Speed = SPEED_SLOW
  │
  ├─► 5. 軌道追従計算 (黒マスク下部〜中間部)
  │      ├─ 黒領域の重心(Cx)を計算
  │      └─ error = TargetX - Cx としてPID制御で Angular Z を算出
  │
  └─► 6. ロボット制御
         └─ Twist(Speed, Angular Z) を /cmd_vel にパブリッシュ
```
