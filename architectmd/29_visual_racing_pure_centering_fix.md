# ARCH_TITLE: visual_racing_pure_centering_fix

## 1. システム概要と決定された採用技術

### システム概要
本設計は、ビジュアルレーシングAIの走行軌道制御を根本的に見直し、「アウト・イン・アウト」制御から**「純粋なセンタリング制御（道なり走行）」**へと設計を変更するためのものである。
画面中心の白線を意図的に無視（画像処理のマスク段階で除外）し、「黒色路面全体の重心」を捉え続けることで、コースのど真ん中を安定して自律走行させることを目的とする。また、画像上部のカーブ検知によるステートマシン機能は、ステアリング制御からは分離し、**「速度の加減速（スローイン・ファストアウト）」のみ**に限定して利用する。

### 決定された採用技術（既存維持）
| 項目 | 採用技術 |
|------|---------|
| 言語 | Python 3.10+ |
| 3Dシミュレータ | Panda3D (既存シミュレータ維持) |

| ROS 2通信・画像処理 | `rclpy`, `geometry_msgs/Twist`, `sensor_msgs/Image`, `cv_bridge`, `OpenCV` (`cv2`) |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` (AI制御側)
ビジュアルサーボのための制御ロジックを「センタリング（中心追従）」に特化させるよう修正する。

*   **【★修正1】不要なオフセットパラメータの削除**
    *   コード上部で定義されている軌道オフセット用パラメータ `OFFSET_OUT` および `OFFSET_IN` を削除する。

*   **【★修正2】白線を除外した純粋な重心（Cx）の算出**
    *   画像処理において、HSV色空間を用いた黒色抽出（例: `BLACK_V_MAX = 50` 以下の領域抽出）を維持する。
    *   白線（高明度）はこの閾値条件により黒マスク（`black_mask`）から自動的に除外されるため、結果として「白線を無視した道幅全体の領域」が得られる。
    *   前回の改修で導入した**画面下部（`lower_mask`）のみ**から `cv2.moments` を用いて黒色重心のX座標 `Cx` を算出する。

*   **【★修正3】ステアリング目標値算出の簡素化（センタリング制御）**
    *   ステート（STRAIGHT, TURNING 等）に応じた目標値（`TargetX`）のオフセット加減算処理をすべて廃止する。
    *   ステアリングの目標は常に「画面のど真ん中」とする。
    *   重心 `Cx` を用いて、制御の誤差（`error`）を以下の式で直接算出する。
        ```python
        # w: 画像の幅
        # 目標値は常に画像中央 (w / 2.0)
        error = (w / 2.0) - Cx
        ```
    *   この `error` をそのまま既存のPID制御（比例・微分制御）に渡し、角速度 `cmd_vel.angular.z` を決定する。

*   **【★修正4】ステートマシンの役割限定（速度制御のみ）**
    *   画面上部（`upper_mask`）の形状分析によるカーブ検知（`PRE_CURVE`, `TURNING`等への遷移）は維持する。
    *   ただし、このステート遷移による影響は**直進速度（`cmd_vel.linear.x`）の切り替えのみ**とする。
    *   直進時（`STRAIGHT`）は `SPEED_FAST`、カーブ時（`PRE_CURVE`, `TURNING`）は `SPEED_SLOW` を出力させる。

## 4. データ・制御の処理フロー

本改修により、ステアリングと速度の制御が完全に分離され、処理フローが以下のようにシンプル化される。

```text
【毎フレームのビジュアルレーシング・サイクル】

1. [Image Callback] 画像の取得とHSVマスク化
   └─ OpenCVで黒色路面マスクを生成。
      （※白線は明度が高いため黒色マスクから自動除外される）

2. [ROI Split] 画像の上下分割
   ├─ upper_mask ──► カーブ先読み（速度制御用）
   └─ lower_mask ──► 足元の重心算出（ステアリング用）

3. [Speed Control] 速度制御（ステート評価）
   ├─ upper_mask を分析し、カーブが近いか判定。
   └─ ステートに応じて cmd_vel.linear.x を設定。（STRAIGHT=高速, TURNING=減速）

4. [Steering Control] センタリング制御（誤差算出）
   ├─ lower_mask から白線を含まない路面全体の黒色重心（Cx）を算出。
   └─ 画面中央とのズレを計算: error = (画面幅 / 2.0) - Cx

5. [Motor Output] コマンド送信
   ├─ PID制御により error からステアリング角速度 cmd_vel.angular.z を計算。
   └─ 機体に対して Publish（常に道幅の中央をキープしつつ、カーブでは安全に減速する）。
```
