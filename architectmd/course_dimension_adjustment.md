# ARCH_TITLE: course_dimension_adjustment

## 1. システム概要と決定された採用技術

### システム概要
本設計は、自動運転AI（ビジュアルレーシングAI）を評価するためのシミュレーション環境において、コースの形状を現実の実機コースの寸法に適合させる改修である。
社長の要望に基づき、直線区間およびカーブ区間の長さ・半径を実寸法へ大幅にスケールアップする。
さらに、シミュレータのバリデーション（コースが始点と終点で閉じることのチェック）を確実に通過させるため、コース全体の幾何学的な整合性を担保する。具体的には、C1・C2のカーブ角度およびL3・L4の直線距離を数センチ〜数度の範囲で微調整し、数学的に完璧な閉路を構築する手法を採用した。

### 決定された採用技術
| 項目 | 採用技術・手法 |
|------|--------------|
| コース幅と基準半径 | コース幅は現状維持（7.0m、中心から左右3.5m）。最内側の線を15.0mとするため、**中心線の旋回半径を 18.5m (15.0 + 3.5)** に統一。 |
| 直線寸法ベース | L1 = 21.0m、L2 = 48.5m を基準値として固定。 |
| 閉路構築の幾何学調整 | コースを完全に閉じるため、C1=68度、C2=112度 に変更。これに伴いX軸・Y軸の釣り合いから L3=39.17m、L4=44.97m を算出し適用する。 |

## 2. フォルダ・ファイル配置案（既存構成への差分）

ファイルの新規追加・削除・配置変更は発生しない。既存のシミュレーション設定ファイルのみを更新する。

```text
📁 src/
  📁 simulation/
    📄 config.py               # ★修正: SEGMENTSパラメータの実寸法への更新
  📁 simulation_base/
    📄 config.py               # ★修正: 同上（simulation/config.pyと同一内容）
```

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `simulation/config.py` および `simulation_base/config.py`
コースの形状を決定する `SEGMENTS` パラメータを更新する。
（※両ファイルで同一の `SEGMENTS` を定義しているため、両方とも同じ値に変更すること）

*   **実装仕様**
    `SEGMENTS` リスト内の各辞書オブジェクトを以下の値に完全に書き換える。

    ```python
    SEGMENTS = [
        {"id": "L1", "type": "straight", "length": 21.0},
        {"id": "C1", "type": "arc",      "radius": 18.5, "angle_deg": 68, "direction": "left"},
        {"id": "L2", "type": "straight", "length": 48.5},
        {"id": "C2", "type": "arc",      "radius": 18.5, "angle_deg": 112, "direction": "left"},
        {"id": "L3", "type": "straight", "length": 39.17},
        {"id": "C3", "type": "arc",      "radius": 18.5, "angle_deg": 90, "direction": "left"},
        {"id": "L4", "type": "straight", "length": 44.97},
        {"id": "C4", "type": "arc",      "radius": 18.5, "angle_deg": 90, "direction": "left"},
    ]
    ```

    *※補足*
    上記以外のパラメータ（ロボットパラメータ、描画パラメータ、カメラシミュレータパラメータ等）は一切変更しない。

## 4. データ・制御の処理フロー

コースデータの生成処理（シミュレータ起動時）のフローは以下の通りとなる。
今回の設定変更により、ステップ2の閉路チェックが確実に通過する。

```text
【コースデータ生成と閉路検証 フロー（シミュレータ起動時）】

1. [Configuration Load]
   └─ `config.py` から `SEGMENTS` (全8セグメント) を読み込む。

2. [Course Points Generation] (CourseGenerator.generate_course_points)
   ├─ 原点(0, 0)からスタート。
   ├─ [L1] 21.0m 直進。
   ├─ [C1] 半径18.5mで左へ68度旋回。
   ├─ [L2] 48.5m 直進。
   ├─ [C2] 半径18.5mで左へ112度旋回。
   ├─ [L3] 39.17m 直進。
   ├─ [C3] 半径18.5mで左へ90度旋回。
   ├─ [L4] 44.97m 直進。
   └─ [C4] 半径18.5mで左へ90度旋回し、原点(0, 0)へ戻る。

3. [Validation Check] (pytest: test_course_is_closed)
   └─ 始点座標と終点座標のユークリッド距離を計算。
      幾何学的に最適化された寸法のため、誤差は COURSE_CLOSE_TOLERANCE (1.0m) を下回り（ほぼ0）、テストをパスする。

4. [Simulation Start]
   └─ 構築された広大な実寸法コース上にロボットが配置され、走行シミュレーションが開始される。
```
