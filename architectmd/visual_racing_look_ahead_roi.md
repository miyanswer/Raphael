# ARCH_TITLE: visual_racing_look_ahead_roi

## 1. システム概要と決定された採用技術

### システム概要
本設計は、ビジュアルレーシングAIノード（`course_lap_node.py`）において発生している「左カーブ進入時に過剰にインカットし、自ら左側の芝生へ突っ込んでしまう不具合」を解消するための改修設計である。

不具合の根本原因は以下の2点である。
1. **視線の固定（足元の偏りへの追従）**: 車体が傾いた際、画像下部（足元）の黒色エリアの偏りに重心（Cx）が引っ張られ、コースの先を正しく見失っていた。
2. **過剰なオフセット値**: カーブ進入時のイン寄せ命令（`OFFSET_IN = -80`）が強すぎたため、急激な左旋回を引き起こしていた。

本改修により、**「視線の先読み（Look-ahead ROI）の導入」**と**「オフセットパラメータの緩和」**を実施し、人間が運転するように「少し先の未来のコース」を見てステアリングを切る安定した走行制御を実現する。

### 決定された採用技術（既存維持）

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` (AI制御ノード)
画像処理コールバック内の重心計算ロジック、およびグローバルパラメータを以下のように改修する。

*   **【★修正1】オフセットパラメータの緩和**
    *   ファイル上部の制御パラメータを以下のように変更し、過剰なステアリング操作を抑制する。
        *   `OFFSET_OUT = 50` → **`20`** に変更
        *   `OFFSET_IN = -80` → **`-20`** に変更

*   **【★修正2】視線の先読み（Look-ahead ROI）の導入**
    *   **重心（Cx）の算出対象**を画像全体ではなく、**「画像の中・上段エリア（遠方のコース）」に限定**する。
    *   芝生の安全判定（EMERGENCY用）は、既存の通り「画像下部」のまま維持すること（ここは変更しない）。
    *   **必須実装ロジック（重心計算部分）:**
        ```python
        # 画像の高さと幅を動的に取得
        h, w = cv_image.shape[:2]
        
        # 1. 制御用の先読みROI（Look-ahead ROI）の設定
        # 例: 画像の高さの 25% 〜 65% の範囲（遠方〜中距離の路面）を切り出す
        roi_top = int(h * 0.25)
        roi_bottom = int(h * 0.65)
        
        # 黒色マスク処理 (既存のBLACK_V_MAX等を使用)
        # ※ マスク作成後、重心計算用のマスクは roi_top より上、および roi_bottom より下を強制的に黒(0)で塗りつぶすか、ROI部分だけでモーメントを計算する
        control_mask = black_mask.copy()
        control_mask[:roi_top, :] = 0
        control_mask[roi_bottom:, :] = 0
        
        # 2. 限定された制御用マスクから重心(Cx)を計算
        M = cv2.moments(control_mask)
        if M["m00"] > 0:
            Cx = int(M["m10"] / M["m00"])
        else:
            Cx = w / 2.0  # 見失った場合は画像中心
        ```

*   **【★確認・徹底事項】誤差計算の動的処理**
    *   前回の修正方針に則り、`400`などのハードコードが完全に排除されているか再確認する。
    *   `error = (w / 2.0) - TargetX` のように、必ず動的取得した画像幅（`w`）から計算された中心座標を用いて誤差を算出すること。

## 4. データ・制御の処理フロー

改修適用後の、1フレームあたりの正しいデータ処理と制御フローは以下の通りとなる。

```text
【毎フレームのビジュアルレーシング制御フロー】

1. [Image Callback] 画像の取得
   └─ /camera/image_raw を受信し、cv_imageに変換 (例: 800x600)
   └─ 画像の高さ(h)と幅(w)を動的に取得

2. [Safety Check] 芝生検知による安全判定
   └─ 画像下部（例: hの70%〜100%）を切り出し、緑色ピクセル割合を計算
   └─ 閾値超過なら EMERGENCY ステートへ移行し、直ちに停止(v=0, w=0)してreturn

3. [Look-ahead ROI Processing] 先読み視点での路面抽出（★本改修のコア）
   ├─ 制御用のマスクとして、画像中上段（例: hの25%〜65%）のみを有効化
   └─ 足元の偏りを無視した遠方の黒色路面から、正しい重心（Cx）を計算する

4. [State & Target Calculation] 目標座標の決定と誤差計算
   ├─ 形状特徴からカーブを検知し、ステート（STRAIGHT / TURNING 等）を決定
   ├─ ステートに応じた緩和されたオフセット(20 または -20)を加算: TargetX = Cx + Offset
   ├─ 動的中心を計算: center_x = w / 2.0
   └─ 誤差の計算: error = center_x - TargetX

5. [PID Control & Action] 制御・出力
   ├─ error を用いてステアリング角速度(w)をPID演算
   ├─ 計算結果（State, Cx, TargetX, Error, v, w）をログ出力
   └─ 算出された Twist を /cmd_vel へ Publish
```
