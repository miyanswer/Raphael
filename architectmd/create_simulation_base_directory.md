# ARCH_TITLE: create_simulation_base_directory

## 1. システム概要と決定された採用技術

### システム概要

現在の安定版シミュレータ（水色の空、白い大地、緑の縁取りを持つバランス型台形コース）のコード群をベースラインとして永続的に保存するため、既存の `simulation` ディレクトリを丸ごと複製し、新たに `simulation_base` ディレクトリを作成する。
これにより、今後の開発で `simulation` 内のコードを大胆に改修しても、いつでも安定版のコードへロールバック・参照することが可能となる。

| 合意項目 | 決定内容 |
|---------|---------|
| バックアップの作成 | 現在の `simulation` ディレクトリをコピーし、`simulation_base` という名前で同階層に配置する |
| 今後の運用方針 | `simulation` は引き続き開発用として利用し、`simulation_base` は安定版の参照・復元用として保持する |

### 決定された採用技術

本件はプログラムロジックの変更ではなく、ファイルシステム上のディレクトリ複製操作（OSコマンド操作）となる。

| 項目 | 採用技術 | 状態 |
|------|---------|------|
| ファイル操作 | OS標準コマンド (`cp -r`) | 確定 |

## 2. フォルダ・ファイル配置案（既存構成への差分）

ワークスペース内に `simulation_base` フォルダが新規に追加される。内容はコピー元と完全に同一である。

```text
📁 src/
  📁 raphael_enterprise/          # 変更なし
  📁 web/                         # 変更なし
  📁 simulation/                  # 変更なし（継続開発用）
  📁 simulation_base/             # ★新規追加（安定版ベースライン）
    📄 __init__.py
    📄 main.py
    📄 course.py
    📄 robot.py
    📄 node_manager.py
    📄 camera_simulator.py
    📄 visualizer.py
    📄 config.py
    📁 logs/
      📄 .gitkeep
    📁 tests/
      📄 __init__.py
      📄 test_course.py
      📄 test_node_manager.py
```

### 差分サマリー

| 操作 | 対象 | 変更内容 | 変更規模 |
|------|------|---------|---------|
| **新規（複製）** | `simulation_base/` ディレクトリ全体 | `simulation/` ディレクトリを中身ごと複製し、同階層に配置する | 中（ファイル操作のみ） |

## 3. 各ファイルの役割と必要な実装仕様

本件においてソースコード内部（Pythonファイル等）のロジック改修は一切発生しない。
実装担当者は、ワークスペースの `src` ディレクトリ内で以下のコマンドを実行し、ディレクトリの完全な複製を行うこと。

### 3-1. ディレクトリ複製コマンド仕様

ターミナル（またはファイルマネージャ）を用いて、以下の通りコピー操作を実行する。

```bash
# ワークスペースの src ディレクトリへ移動
cd ~/raphael_ws/src

# simulation ディレクトリを再帰的にコピーして simulation_base を作成
cp -r simulation simulation_base
```

**【実装担当者への確認事項】**
- コピー先の `simulation_base/` の中に、元の `.py` ファイル群や `logs/`、`tests/` などのサブディレクトリが漏れなく含まれていることを確認すること。
- コピー完了後、元の `simulation/` 内のファイルが消失・破損していないことを確認すること。

## 4. データ・制御の処理フロー

本改修はプログラムの実行フローには影響を与えない。運用および構成管理のフローは以下のようになる。

```text
[構成管理フロー]
1. 開発環境の準備
   └─► OSコマンドにより `simulation/` フォルダを `simulation_base/` として複製。

2. 今後の開発サイクル
   ├─► 新機能の追加・改修: `simulation/` 内のコードを変更して実行。
   └─► 過去の安定状態の確認・復元: `simulation_base/` 内のコードを参照・コピー。
```
