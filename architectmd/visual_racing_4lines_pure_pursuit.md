# ARCH_TITLE: visual_racing_4lines_pure_pursuit

## 1. システム概要と決定された採用技術

### システム概要
本設計は、自動運転AI（ビジュアルレーシングAI）の超軽量スキャンライン制御に対し、**「4本スキャンラインによる高精度ピュアパースート（先読み）制御」**を導入する改修である。
従来の設計から抽出ラインをさらに増やし、「カーブ検知用（1本）」と「ステアリング補間用（3本：先読み・中間・近景）」に役割を完全分離する。これにより、コースの変化に対する解像度が飛躍的に向上し、複雑なコーナーにおいても急ハンドルを防ぎつつ、路面に吸い付くような理想的で滑らかなアウト・イン・アウトの走行軌道を実現する。

### 決定された採用技術
| 項目 | 採用技術・手法 |
|------|--------------|
| 画像抽出手法 | NumPyによる複数1次元スライス抽出（Y軸 0.50, 0.55, 0.65, 0.75 の計4本） |
| 速度制御ロジック | 最上段ライン（0.50）によるカーブ事前検知および減速（SPEED_SLOW）ステート切り替え |
| 先読みステアリング制御 | 下段3ライン（0.55, 0.65, 0.75）の重心に基づく3点加重平均による目標軌道（ターゲットX）の補間計算 |
| モーター制御 | 補間ターゲットと画面中央との1次元誤差に基づくPID制御 |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py`
スキャンライン定数を4本構成へ再定義し、Image Callback内のステアリング誤差計算ロジックを刷新する。

*   **スキャンライン定数の再定義と追加**
    既存の定数を以下の通りに変更・追加する。
    *   `SCAN_Y_CURVE_RATIO = 0.50` （カーブ検知・減速判定専用）
    *   **追加:** `SCAN_Y_FAR_STEER_RATIO = 0.55` （先読み補間用）
    *   `SCAN_Y_MID_STEER_RATIO = 0.65` （中間補間用）
    *   `SCAN_Y_NEAR_STEER_RATIO = 0.75` （近景基準用 / 旧 `SCAN_Y_STEER_RATIO` から名称と値を変更）
    *   **追加:** 3点加重平均用のウェイト定数（例: `WEIGHT_NEAR = 0.5`, `WEIGHT_MID = 0.3`, `WEIGHT_FAR = 0.2`）を定義し、チューニング可能にする。

*   **スキャンライン画像処理ロジックの実装（Image Callback内）**
    *   1画像のHSV変換（Vチャネル抽出）後、高さ（height）に各RATIOを掛けた4つのY座標インデックスを算出する。
    *   **速度制御（0.50ラインの処理）**:
        従来通り、0.50のラインから横1行データを抽出し、黒色ピクセルの幅や中心ズレを判定。カーブ条件を満たした場合、直進モード（`SPEED_FAST`）から減速モード（`PRE_CURVE` ➔ `SPEED_SLOW`）へ切り替える。
    *   **ステアリング制御（0.55, 0.65, 0.75ラインの処理）**:
        各ラインの横1行データから、`BLACK_V_MAX` 以下の条件を満たす黒色路面の重心X座標をそれぞれ算出する。
        *   `center_near_x` (0.75ラインから算出)
        *   `center_mid_x` (0.65ラインから算出)
        *   `center_far_x` (0.55ラインから算出)

*   **目標軌道（ターゲットX）の算出と誤差計算**
    *   算出した3つの重心を設定したウェイト定数を用いて加重平均し、最終的な目標点（`target_x`）を算出する。
        *   計算式（例）: `target_x = (center_near_x * WEIGHT_NEAR) + (center_mid_x * WEIGHT_MID) + (center_far_x * WEIGHT_FAR)`
    *   画像中央座標（`width / 2.0`）と `target_x` のズレを算出し、これをステアリングの `error` とする。
        *   計算式: `error = (width / 2.0) - target_x`

*   **PID制御と出力**
    *   算出した新しい `error` を既存のPID計算（`STEER_KP`, `STEER_KD`）に適用し、角速度 `cmd_vel.angular.z` を決定する。

## 4. データ・制御の処理フロー

改修後のシステムにおける処理フローは以下の通りとなる。

```text
【ビジュアルレーシング・4本スキャンライン処理フロー（毎フレーム）】

1. [Image Callback] 
   └─ カメラ画像取得およびHSV空間（Vチャネル等）への変換（重い2次元処理はここまで）。

2. [Scanline Extraction] 1次元データの抽出（計4本）
   ├─ Y = height * 0.50 の横1行を抽出（カーブ検知ライン）
   ├─ Y = height * 0.55 の横1行を抽出（先読みライン）
   ├─ Y = height * 0.65 の横1行を抽出（中間ライン）
   └─ Y = height * 0.75 の横1行を抽出（近景ライン）

3. [Speed Control] カーブ事前検知・速度制御
   ├─ カーブ検知ライン (0.50) の黒色ピクセル情報をチェック。
   └─ カーブ進入を検知した場合、速度を SPEED_FAST から SPEED_SLOW へ切り替え。

4. [Steering Control] 3ライン加重平均による先読みセンタリング制御
   ├─ 近景ライン (0.75) から手前の重心（center_near_x）を算出。
   ├─ 中間ライン (0.65) から中間の重心（center_mid_x）を算出。
   ├─ 先読みライン (0.55) から少し先の重心（center_far_x）を算出。
   ├─ 3点の重心を加重平均し、目標点 target_x を計算。
   │  例: (center_near_x * 0.5) + (center_mid_x * 0.3) + (center_far_x * 0.2)
   ├─ 目標点とのズレ error = (画面幅 / 2.0) - target_x を計算。
   └─ PID制御により error を角速度コマンド (cmd_vel.angular.z) へ変換。

5. [Motor Output] コマンド送信
   └─ 最新の cmd_vel (速度・角速度) を機体へ Publish（先読みに基づく滑らかで安定した走行）。
```
