# ARCH_TITLE: visual_racing_pure_pursuit_scanline

## 1. システム概要と決定された採用技術

### システム概要
本設計は、自動運転AI（ビジュアルレーシングAI）の超軽量スキャンライン制御に対し、**「先読み制御（ピュアパースート的アプローチ）」**を導入する改修である。
従来の「近景（手前）」のみに依存したステアリング制御から、「中近景（少し先）」と「近景」の2点の重心を滑らかに結ぶ方式へアップグレードする。これにより、計算負荷を極小（1次元データ処理）に保ったまま、カーブ進入時に急ハンドルにならない滑らかで理想的なコーナリングラインの走行を実現する。

### 決定された採用技術
| 項目 | 採用技術・手法 |
|------|--------------|
| 画像抽出手法 | NumPyによる複数1次元スライス抽出（近景、中近景、中景の計3本） |
| 先読みステアリング制御 | 2点の重心（中点）の加重平均による目標軌道（ターゲットX）の補間計算 |
| 制御ロジック | 補間ターゲットと画面中央との1次元誤差に基づくPID制御 |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py`
スキャンライン方式に第3のライン（中近景）を追加し、ステアリングのための誤差計算ロジックを刷新する。

*   **定数の追加と定義**
    *   既存の `SCAN_Y_STEER_RATIO = 0.80`（近景）および `SCAN_Y_CURVE_RATIO = 0.55`（中景）に加え、新たに中近景用の定数を追加する。
    *   **追加:** `SCAN_Y_MID_STEER_RATIO = 0.65` （画面上部から65%の位置。先読み補間用）
*   **スキャンライン画像処理ロジックの実装（Image Callback内）**
    *   画像のHSV変換後、Y座標のインデックスを3つ（`y_near`, `y_mid`, `y_curve`）算出する。
    *   **2ライン同時の重心抽出**:
        近景（`0.80`）および中近景（`0.65`）の1行データ（Vチャネル）をそれぞれ抽出し、`BLACK_V_MAX` 以下の条件を満たすピクセルから `np.where` を用いて黒色路面の両端X座標（`min_x`, `max_x`）を取得する。
        これにより、「手前の重心 `center_near_x`」と「少し先の重心 `center_mid_x`」を同時に算出する。
*   **目標軌道（ターゲットX）の算出と誤差計算**
    *   算出した2つの重心を加重平均でブレンドし、滑らかな目標点（`target_x`）を算出する。
        *   計算式（例）: `target_x = (center_near_x * 0.6) + (center_mid_x * 0.4)`
    *   画像中央座標（`width / 2.0`）と `target_x` のズレを算出し、これをステアリングの `error` とする。
        *   計算式: `error = (width / 2.0) - target_x`
*   **PID制御とカーブ検知の統合**
    *   算出した新しい `error` を既存のPID計算（`STEER_KP`, `STEER_KD`等を用いた処理）にそのまま適用し、角速度 `cmd_vel.angular.z` を決定する。
    *   中景（`0.55`）を利用したカーブ検知・速度状態遷移（`PRE_CURVE`時の `SPEED_SLOW` への切り替え等）は既存のロジックを維持し、ステアリング制御と並行して動作させる。

## 4. データ・制御の処理フロー

改修後のシステムにおける処理フローは以下の通りとなる。

```text
【ビジュアルレーシング・先読みスキャンライン処理フロー（毎フレーム）】
1. [Image Callback] 画像取得およびHSV空間への変換（重い2次元処理はここまで）。
2. [Scanline Extraction] 1次元データの抽出（計3本）
   ├─ Y = height * 0.80 の横1行を抽出（近景ライン: センタリング用）
   ├─ Y = height * 0.65 の横1行を抽出（中近景ライン: 先読み用）
   └─ Y = height * 0.55 の横1行を抽出（中景ライン: カーブ検知用）

3. [Speed Control] 中景ラインによるカーブ検知・速度制御
   ├─ 中景ラインの黒色ピクセルの幅や中心のズレをチェック。
   └─ カーブ条件を満たした場合、直進モードから減速モード（SPEED_SLOW）へ切り替え。

4. [Steering Control] 近景・中近景ラインによる先読みセンタリング制御
   ├─ 近景ラインから手前の重心（center_near_x）を算出。
   ├─ 中近景ラインから少し先の重心（center_mid_x）を算出。
   ├─ 加重平均により目標点 target_x を計算: (center_near_x * 0.6) + (center_mid_x * 0.4)
   ├─ 目標点とのズレ error = (画面幅 / 2.0) - target_x を計算。
   └─ PID制御を用いて error を角速度コマンド cmd_vel.angular.z へ変換（カーブ手前からの滑らかな切り込みを実現）。

5. [Motor Output] コマンド送信
   └─ 最新の cmd_vel を機体へ Publish（超低遅延でキレと滑らかさを両立した走行）。
```
