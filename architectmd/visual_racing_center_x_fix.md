# ARCH_TITLE: visual_racing_center_x_fix

## 1. システム概要と決定された採用技術

### システム概要
本設計は、ビジュアルレーシングAI（`course_lap_node.py`）において発生していた「直進時の不要な左旋回」および「カーブ時の過剰な左への切れ込み（コースアウト）」という不具合を解消するための改修設計書である。
不具合の根本原因は、ステアリング制御のための誤差（Error）計算において、画像中心のX座標が「400」等の固定値に設定されていたことにある。実際のシミュレータ画像（幅640px等）に合わせた動的な画面中心（`center_x`）の算出ロジックを導入することで、正しく「アウト（右側）」および「イン（左側）」を狙う軌道制御（アウト・イン・アウト）を実現する。

### 決定された採用技術（既存維持）
| 項目 | 採用技術 |
|------|---------|
| 言語 | Python 3.10+ |
| フレームワーク | ROS 2 (rclpy) |
| 画像処理 | OpenCV (`cv2`), `cv_bridge` |
| メッセージ型 | `geometry_msgs/Twist`, `sensor_msgs/Image` |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py` (AI制御ノード)
画像コールバック関数内のビジュアルサーボ（PID制御）に関する計算処理に対して、以下の改修を加える。

*   **【★修正】画像中心の動的取得と誤差（error）算出ロジックの修正**
    *   制御ロジック内で `error = 400 - target_x` のように固定値が使用されている箇所（またはそれに類する誤差算出部分）を特定し、削除する。
    *   OpenCVの画像配列（`cv_image`）から動的に画像の幅を取得し、中心座標を計算するロジックに置き換える。
    *   **具体的な実装ロジック（以下を適用）:**
        ```python
        # 画像幅の動的取得
        image_width = cv_image.shape[1]
        
        # 画面中心座標の算出 (640px幅であれば320.0となる)
        center_x = image_width / 2.0
        
        # 誤差(Error)の計算
        error = center_x - target_x
        ```
    *   **適用結果の挙動確認:**
        *   反時計回りのコースにおいて、直線時（`OFFSET_OUT = 50`）は目標が右に寄るため、車体は右旋回してアウトコース（右側）へアプローチする。
        *   カーブ時（`OFFSET_IN = -80`）は目標が左に寄るため、車体は左旋回してインコース（左側）へアプローチし、かつ切り込みすぎ（暴走）を防ぐことができる。

## 4. データ・制御の処理フロー

本改修を適用した後の、1フレームあたりのデータ処理と制御フローは以下の通りとなる。

```text
【毎フレームのビジュアルレーシング制御フロー】

1. [Image Callback] 画像の取得
   └─ /camera/image_raw を受信し、cv_imageに変換

2. [Image Processing] 特徴抽出とステート決定
   ├─ マスク処理により黒色路面および緑色（芝生）を抽出
   ├─ 安全判定（芝生比率によるEMERGENCY判定と停止スキップ）
   └─ 走行ステート（STRAIGHT, PRE_CURVE, TURNING等）の判定と重心(Cx)の算出

3. [Dynamic Center & Error Calc] 動的誤差計算（★今回の改修ポイント）
   ├─ target_x = Cx + offset (ステートに応じたオフセット値)
   ├─ image_width = cv_image.shape[1]  (画像幅の取得: ex.640)
   ├─ center_x = image_width / 2.0     (画面中心X座標: ex.320.0)
   └─ error = center_x - target_x      (ステアリング用の誤差)

4. [PID Control] 制御値(v, w)の算出
   ├─ 直線/カーブに応じた目標速度(v)の決定
   └─ error を用いたPID演算による目標角速度(w)の決定

5. [Command Output] ロボットへのコマンド送信
   └─ 算出された v, w を Twist メッセージとして /cmd_vel へPublish
```
