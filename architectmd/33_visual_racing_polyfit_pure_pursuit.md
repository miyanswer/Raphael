# ARCH_TITLE: visual_racing_polyfit_pure_pursuit

## 1. システム概要と決定された採用技術

### システム概要
本設計は、自動運転AI（ビジュアルレーシングAI）のピュアパースート制御において、従来の「3点加重平均」による単一ポイント追従を廃止し、**「2次関数近似（曲線フィッティング）による滑らかな軌道追従」**へと高度化する改修である。
先読みラインの間隔を調整し、抽出した3点の重心座標から近似曲線（2次関数）を算出することで、カメラノイズや急カーブでもターゲット座標が暴れることを防ぎ、実車に近い滑らかで自然なステアリング挙動を実現する。

### 決定された採用技術
| 項目 | 採用技術・手法 |
|------|--------------|
| 先読みライン設定 | Y軸 0.60 (先読み), 0.65 (中間), 0.75 (近景) の3ラインへ間隔を最適化 |
| 曲線フィッティング | `numpy.polyfit(Y配列, X配列, 2)` を用いた2次関数近似（$X = aY^2 + bY + c$） |
| 目標軌道算出 | 算出した2次関数に、追従基準となるY座標を代入して理想の目標X座標（`target_x`）を逆算 |
| 誤差計算・制御 | 画面中央と `target_x` のズレを1次元誤差とし、既存のPID制御（角速度）へ適用 |

## 3. 各ファイルの役割と必要な実装仕様

### 3-1. `course_lap_node.py`
スキャンライン定数を更新し、加重平均ロジックを廃止して2次関数近似（polyfit）の軌道算出ロジックを実装する。

*   **制御パラメータ・定数の変更**
    *   **変更**: `SCAN_Y_FAR_STEER_RATIO = 0.60` （旧 `0.55` から変更）
    *   **削除**: 3点加重平均ウェイト定数（`WEIGHT_NEAR`, `WEIGHT_MID`, `WEIGHT_FAR` は不要となるため削除）
    *   **追加**: 軌道追従の基準とするY座標比率（先読み0.60と中間0.65の中間地点などを想定）
        *   例: `TRACKING_TARGET_Y_RATIO = 0.625`

*   **スキャンライン画像処理と重心算出（Image Callback内）**
    *   速度制御用ライン（0.50）の処理は既存のまま維持。
    *   ステアリング補間用3ライン（0.60, 0.65, 0.75）から、それぞれ黒色路面の重心X座標を算出する。
        *   `center_near_x` (0.75ラインから算出)
        *   `center_mid_x` (0.65ラインから算出)
        *   `center_far_x` (0.60ラインから算出)

*   **2次関数近似（Polyfit）による `target_x` の算出**
    1.  抽出した3点の画像上のY座標（ピクセル値）と、算出された重心X座標を配列化する。
        *   `Y_array = np.array([height * 0.75, height * 0.65, height * 0.60])`
        *   `X_array = np.array([center_near_x, center_mid_x, center_far_x])`
    2.  `np.polyfit(Y_array, X_array, 2)` を実行し、2次関数の係数 `(a, b, c)` を取得する。
    3.  追従の基準となるY座標（`y_ref = height * TRACKING_TARGET_Y_RATIO`）を定義する。
    4.  取得した係数を用いて、理想の目標点 `target_x` を逆算する。
        *   `target_x = a * (y_ref**2) + b * y_ref + c`

*   **誤差計算とPID制御への適用**
    *   画像中央座標（`width / 2.0`）と `target_x` のズレを算出し、これをステアリングの `error` とする。
        *   `error = (width / 2.0) - target_x`
    *   算出された `error` を既存のPID計算へ渡し、角速度 `cmd_vel.angular.z` を決定・Publishする。

## 4. データ・制御の処理フロー

```text
【ビジュアルレーシング・Polyfit曲線軌道追従フロー（毎フレーム）】

1. [Image Callback] 
   └─ カメラ画像取得およびHSV空間（Vチャネル等）への変換。

2. [Scanline Extraction] 1次元データの抽出（計4本）
   ├─ Y = height * 0.50 の横1行を抽出（カーブ検知ライン）
   ├─ Y = height * 0.60 の横1行を抽出（先読みライン）
   ├─ Y = height * 0.65 の横1行を抽出（中間ライン）
   └─ Y = height * 0.75 の横1行を抽出（近景ライン）

3. [Speed Control] カーブ事前検知・速度制御
   ├─ カーブ検知ライン (0.50) でカーブ進入を検知した場合、速度を減速ステートへ切り替え。

4. [Steering Control] 2次関数近似による滑らかな軌道追従
   ├─ 近景(0.75), 中間(0.65), 先読み(0.60) の3ラインから黒色路面の重心 (X座標) を算出。
   ├─ Y座標配列とX重心配列を用いて np.polyfit(Y_array, X_array, 2) を実行し、係数(a,b,c)を取得。
   ├─ 追従基準Y座標（例: height * 0.625）を2次関数に代入し、滑らかな曲線上の target_x を逆算。
   ├─ 目標点とのズレ error = (画面幅 / 2.0) - target_x を計算。
   └─ PID制御により error を角速度コマンド (cmd_vel.angular.z) へ変換。

5. [Motor Output] コマンド送信
   └─ 最新の cmd_vel (速度・角速度) を機体へ Publish。
```
